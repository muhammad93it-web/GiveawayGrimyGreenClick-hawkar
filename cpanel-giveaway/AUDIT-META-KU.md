# ڕاپۆرتی پشکنینی هێنانی کۆمێنتە مێژووییەکانی Facebook

**وەشان:** ١.٤.٠  
**بەرواری پشکنین:** ٢٠٢٦-٠٨-٢٤

## ١. هۆکاری سەرەکی

هێنانی مێژوویی لە وێبسایتی ڕاستەوخۆ تەواو بووە: ٢ پەڕە و ١٣٠ کۆمێنت، بێ هەڵە. تەنها ٧ کۆمێنت خانەی ناسنامەیان هەیە و ١٢٣ کۆمێنت خانەی `from` ـیان لە وەڵامی Meta ـدا نییە. ئەو ٧ کۆمێنتە ناسنامەدارەش بۆ یەک کەسن.

کەواتە کێشەکە ناتەواوبوونی پەڕەبەندی یان ونبوونی کۆمێنت نییە. هۆکاری ماوە، نەگەڕاندنەوەی ناسنامەی نووسەری کۆمێنتە مێژووییەکانە لەلایەن Meta. زۆرترین هۆکاری ئەمە نەبوون یان پەسەندنەکرانی Advanced Access بۆ `Business Asset User Profile Access` ـە.

کۆد هیچ ناو، وێنە یان ناسنامەیەک حدس ناکات. کۆمێنتی بێ `from.id` وەک کۆمێنتێکی چارەسەرنەکراو هەڵدەگیرێت و لە هەڵبژاردنی براوە بەپێی کەس بەشداری پێناکرێت.

## ٢. شوێنە بەرپرسیارەکان

- چوونەژوورەوەی Meta OAuth: `app/Meta.php`، `Meta::login()` و `Meta::callback()`
- دروستکردن و هەڵگرتنی Page Access Token: `Meta::callback()`، داتای `/me/accounts`؛ مۆڵەتەکان بە کۆدکردنەوە لە `meta_connections` هەڵدەگیرێن
- هێنانی پۆستەکان: `Meta::posts()` و `Meta::post()`
- هێنانی کۆمێنتی مێژوویی: `Meta::commentPage()`، `Meta::replyPage()` و `CommentImport::advance()`
- Webhook: `Http::webhook()`؛ واژۆ پشکنین دەکات و بە خێرایی وەڵام دەدات، پاشان کاری خشتەکراو بە هەمان هێنانەوەی قوفڵکراو داتا نوێ دەکاتەوە
- کۆکردنەوەی بەشداربووان: `Giveaway::aggregateComments()` و `CommentImport::finalize()`

## ٣. Graph API و مۆڵەتە داواکراوەکان

- Graph API: `v26.0`
- مۆڵەتە داواکراوەکان:
  - `pages_show_list`
  - `pages_read_engagement`
  - `pages_read_user_content`
  - `instagram_basic`
  - `instagram_manage_comments`
- `pages_manage_engagement` داوا ناکرێت، چونکە ئەپ وەڵام ناداتەوە و کۆمێنت ناشارێتەوە یان ناسڕێتەوە.
- هێنانی کۆمێنتی Facebook بە **Page Access Token** ئەنجام دەدرێت، نەک بە User Access Token.

## ٤. مۆڵەتە وەرگیراوەکانی ئێستا

ناوی مۆڵەتە وەرگیراوەکان لە API ـی گشتی دەرناکەون و نابێت بە گومان ڕاپۆرت بکرێن. لە وەشانی ١.٤.٠ دوگمەی «پشکنینی مۆڵەتەکانی Meta» زیاد کراوە. ئەو دوگمەیە `/me/permissions` بە User Access Token پشکنین دەکات، بەڵام تەنها ناوی مۆڵەت و دۆخیان دەگەڕێنێتەوە؛ هیچ مۆڵەتێک بۆ وێبگەڕ نانێردرێت.

`Business Asset User Profile Access` لە `/me/permissions` پشکنین ناکرێت. دەبێت بە دەستی لە Meta App Review پشکنین بکرێت.

## ٥. نموونەی پاککراوەی کۆمێنت

پشکنینی نوێ تەنها شێوەی خانەکان دەگەڕێنێتەوە، نەک نرخە ڕاستەقینەکان:

```json
{
  "commentReturned": true,
  "idPresent": true,
  "messageFieldPresent": true,
  "createdTimePresent": true,
  "fromPresent": false,
  "fromIdPresent": false,
  "fromNamePresent": false,
  "nextPagePresent": true,
  "rawValuesIncluded": false
}
```

ئەمە نموونەی شێوەی کۆمێنتێکە کە Meta کۆمێنتەکە دەگەڕێنێتەوە، بەڵام زانیاریی نووسەر نادات.

## ٦. گۆڕانکاریی بنکەی داتا

`database/migrate-v1.4.0.sql`:

- `giveaways.include_replies` زیاد دەکات بۆ هەڵبژاردنی تەنها کۆمێنتە سەرەکییەکان یان لەگەڵ وەڵامەکان.
- `comment_import_runs.import_version` ئەگەر پێشتر نییە زیاد دەکات.
- `comment_import_runs.include_replies` زیاد دەکات تا هێنانەوە بە هەمان یاسای ژماردن بەردەوام بێت.
- `giveaways.sync_requested` زیاد دەکات تا webhook ـی واژۆکراو داوای وێنەی نوێی کۆمێنتەکان بکات، بێ ئەوەی کاری خشتەکراو هەر ٥ خولەک هێنانەوەی تەواو دووبارە بکاتەوە.
- فایلەکە ئەگەر نوێکردنەوەی ١.٣.٢ پێشتر جێبەجێ کرابێت، دووبارە ستونەکە زیاد ناکات.

## ٧. چاکسازییەکانی وەشانی ١.٤.٠

- هەوڵدانەوەی سنووردار بۆ هەڵە کاتییەکانی Meta و سنووری داواکاری.
- دەستپێکردنی خۆکاری هێنانەوە دوای هەڵبژاردنی پۆست.
- دوگمەی بەردەوامکردن و هەوڵدانەوە.
- پشکنینی مۆڵەت بەبێ ئاشکراکردنی مۆڵەت.
- نموونەی پارێزراوی بوون/نەبوونی `from.id` و `from.name`.
- جیاکردنەوەی دوو کەس بە هەمان ناو، بە ناسنامەی جێگیر.
- لابردنی وێنەی پرۆفایل لە داواکاریی سەرەکی، تا کێشەی وێنە هەموو هێنانەوەکە نەشکێنێت.
- هەڵبژاردنی تەنها کۆمێنتە سەرەکییەکان یان لەگەڵ وەڵامەکان.
- پاراستنی `filter=toplevel` و پشکنینی ناوخۆیی بۆ ئەوەی وەڵامەکان بە هەڵە لە دۆخی «تەنها سەرەکی» نەژمێردرێن.
- وەستاندنی دووبارەکردنەوەی بێکۆتاییی هێنانەوەی تەواوبوو؛ دوگمەی دەستی یان webhook تەنها هۆکاری دەستپێکردنی وێنەی نوێن.
- شاشەی گشتی هیچ ئاگاداریی مۆڵەت یان ناسنامە پیشان نادات.

## ٨. ئەنجامی وێبسایتی ڕاستەوخۆ

ئەم ژمارانە لە وەڵامی گشتیی `https://giveaway.mang-herbal.com/api/giveaways/current` لە ٢٠٢٦-٠٨-٢٤ وەرگیراون؛ ئەنجامی تاقیکردنەوەی ساختە نین:

- کۆی کۆمێنت: ١٣٠
- کۆمێنتی ناسنامەدار: ٧
- کۆمێنتی بێ ناسنامە: ١٢٣
- بەشداربووی ناسنامەدار: ١
- پەڕەی پشکنراو: ٢
- دۆخی هێنانەوە: تەواو
- هەڵەی دوا هێنانەوە: نییە

ئەم ئەنجامە پشتڕاست دەکاتەوە کە هەموو پەڕەکان تەواو بوون، بەڵام Meta ناسنامەی زۆربەی کۆمێنتە مێژووییەکانی نەداوە.

## ٩. هەنگاوە دەستییەکانی Meta

1. لە Meta Developer Dashboard بچۆ بۆ App Review یان Permissions and Features.
2. Advanced Access بۆ `pages_read_engagement` و `pages_read_user_content` پشکنین بکە.
3. `Business Asset User Profile Access` بدۆزەوە و داوای Advanced Access/Review بۆ بنێرە.
4. دڵنیابە ئەدمینی پەیج کە ئەپەکە دەبەستێتەوە Full Control ـی پەیجەکەی هەیە.
5. دوای پەسەندکردنی Meta، لە داشبۆرد «نوێکردنەوەی مۆڵەتەکانی Meta» دابگرە و دووبارە ڕێگە بدە.
6. «پشکنینی مۆڵەتەکانی Meta» دابگرە و دۆخی مۆڵەتەکان و نموونەی `from` ببینە.
7. «بەردەوامکردنی هێنانەوە» دابگرە تا هێنانەوەی نوێ ناسنامەکان دووبارە پشکنین بکات.

ئەگەر دوای پەسەندکردنی Advanced Access و بەستنەوەی نوێ هێشتا `from` نەهات، سنوورداری لەلایەن Meta ـە و بە کۆد یان حدسکردن نابێت تێپەڕێندرێت.
